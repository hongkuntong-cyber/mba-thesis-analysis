# 研究协议修订 2.0：理论先行的特征准入门

修订日期：2026-08-31  
适用分支：`analysis/theory-first-feature-gate`  
状态：在任何新版特征组合或 K 值计算前冻结

## 1. 修订原因

协议 1.x 将 12 个早期指标合称为“候选特征”，同时又在组合阶段排除部分恒等或冲突关系。这混淆了三个不同层级：特征长名单、事前准入审查和正式确认性候选池，也无法充分回答“为什么恰好是 12 项”。

本修订改为理论先行：候选特征数量不预设，正式候选池只能由事前文献证据与逻辑审查产生。现阶段仅 `ADI` 与 `CV2` 具有明确的间歇性需求分类文献依据，因此只冻结二者为理论锚点。

## 2. 非追溯性声明

仓库中既有特征网格、聚类、预测与留出结果已经被查看。本修订不得被解释为对既有结果的追溯性预注册，也不得删除、覆盖或重新命名旧结果。旧结果继续作为历史探索性材料保留。

新版方法只有在以下条件全部满足后，才能产生新的确认性结果：

1. 文献检索协议已单独提交；
2. 特征证据登记表已完成并单独提交；
3. 正式候选池由登记表自动生成；
4. 候选池提交发生在新版聚类指标运行之前；
5. 真正确认性验证使用此前未查看的新数据或新留出窗口。

## 3. 已冻结的理论基准

基础特征集固定为：

`F0 = {ADI, CV2}`

- `ADI`：平均需求间隔，按 `N_observed / N_positive` 计算；
- `CV2`：正需求量样本标准差除以正需求量均值后平方，方差自由度 `ddof=1`。

两者的依据为 Syntetos、Boylan 与 Croston（2005）提出的间歇性需求分类维度，以及 Kostenko 与 Hyndman（2006）对分类边界的进一步推导。

文献依据支持的是特征构念，不自动证明 Ward、任何 K 值或任何簇—预测模型映射。

## 4. 补充特征准入标准

不预设补充特征数量。任一补充特征只有同时满足以下全部条件，才可标记为 `admitted_supplementary`：

1. 至少有一篇同行评议的原始研究明确将其用于需求分类、需求聚类、需求画像或预测方法选择；
2. 数学公式、时间粒度、零值处理、缺失处理和最低历史长度能够在看结果前冻结；
3. 可以使用研究允许的数据字段计算；
4. 不使用预测起点后的信息；
5. 代表 `ADI` 与 `CV2` 尚未覆盖的理论构念；
6. 不与已准入特征存在精确恒等、确定性推导或同一构念的重复表示；
7. 具备面向小型企业的清晰解释。

综述、教材、博客和业务经验可以帮助发现文献，但不能作为唯一的准入依据。

## 5. 状态与失败关闭规则

证据登记表中的状态仅允许：

- `admitted_anchor`
- `admitted_supplementary`
- `pending_literature`
- `rejected_exact_identity`
- `rejected_construct_duplicate`
- `rejected_formula_unfrozen`
- `rejected_data_unavailable`
- `profile_only`
- `exploratory_only`

正式候选池只读取 `admitted_anchor` 与 `admitted_supplementary`。任何 `pending`、`rejected`、`profile_only` 或 `exploratory_only` 特征进入确认性组合时，程序必须停止并报错，而不是静默跳过。

## 6. 正式组合与主特征集

若文献审查后有 `m` 个补充特征通过准入，则正式候选池大小为 `2 + m`。组合必须包含 `ADI` 与 `CV2`，其余组合规则在证据登记表冻结时一并确定。

最终主特征集不得在本修订中预设。新版数据只可按照事前冻结的 Silhouette、80% 子样本稳定性 ARI、簇规模、Raw/V2 一致性、样本门槛敏感性和简约性规则，从合规组合中进行选择。预测结果不得参与聚类特征选择。

如果没有补充特征通过准入，`ADI + CV2` 即为唯一确认性特征集；特征数量少不构成方法缺陷。

## 7. 版本治理

任何新增或变更特征状态必须：

1. 保留旧登记表；
2. 新增协议版本号；
3. 写明新增文献、公式或数据依据；
4. 说明变更发生在查看哪些结果之后；
5. 在新的特征—K 网格运行之前提交。

本修订只替代协议 1.x 中“预设 12 项正式候选特征”的表述，不修改原始数据、V2 清洗、样本门槛、Ward、K=2–6、稳定性协议或预测评价口径。
