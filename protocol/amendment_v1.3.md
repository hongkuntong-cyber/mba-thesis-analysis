# 研究协议修订 1.3：K=3 与轻量路由的可执行判定线

修订日期：2026-08-30  
修订时点：已查看修订 1.2 所述 5 次聚类预检；尚未运行正式 500 次稳定性检验，尚未运行或查看任何预测结果。  
修订原因：协议 1.0 给出了 K=3 和“稳定增益”的原则，但未把“可重复”“非极小簇”“基本稳定”和“准确率接近”转化为确定性判定线。

本修订只把既有原则操作化，不改变特征范围、K 范围、模型池、回测窗口或主要指标。

## 1. K=3 的通过线

K=3 只有同时满足以下全部条件，才通过为主聚类：

1. 在最终确认性特征组合内，K=3 未被 K=2 在 Silhouette 和稳定性 ARI 中位数上同时支配。
2. 500 次 80% 子样本中，三个匹配簇的 Jaccard 中位数均不低于 0.75。
3. 完整样本的每个簇同时不少于 10 个 SKU 且不少于样本的 5%，避免把极小异常集合解释为独立需求类型。
4. 每个簇相对其最近簇，至少在 ADI、CV²、nonzero_mean、acf1 四个原始尺度画像中的一个维度具有不小于 0.5 个合并标准差的中位数差异；该条件只验证独立画像，不使用预测结果。
5. Raw 与 V2 的共同 SKU 标签 ARI 不低于 0.80。
6. 正销量周数 ≥5 与 ≥10 样本的共同 SKU 标签 ARI 不低于 0.70。
7. 三个簇均能给出不依赖预测优劣的独立需求结构解释；若数值线通过但第三簇只能解释为异常残差，仍判为不通过并列出证据。

任一条件失败时，K=3 不作为主结果，但保留为探索性结果。K=4–6 仍完整报告，不因本判定线而跳过。

## 2. 预测价值与模型路由

前 5 个开发窗口按 SKU 形成路由，规则冻结如下：

1. 路由损失使用 MAE。对同一 SKU、同一起点，MAE 与 MASE 的模型排序在 MASE 分母有效时完全一致；MAE 还能保留 MASE 分母为 0 的 SKU。
2. 至少有 3 个完整开发起点，候选模型才有路由资格。
3. 候选模型须在至少 3 个开发起点中成为该 SKU 的最低 MAE 模型；并列时按 `MA4_proxy → Naive → SES → ADIDA2 → Zero` 的低维护优先顺序处理。
4. SES 或 ADIDA2 除满足第 3 条外，其开发期平均 MAE 必须分别比 MA4_proxy、Naive 和 Zero 均至少低 5%，才进入预测管理。
5. MA4_proxy 或 Naive 除满足第 3 条外，必须严格优于 Zero，才进入预测管理；两者开发期平均 MAE相差不足 2% 时优先 MA4_proxy，以维持企业统一方案的可理解性。
6. 若不存在合格预测模型：开发期实际销量不高于该组不可预测 SKU 的中位数者进入规则管理并回退 Zero；高于中位数者进入人工复核，留出比较中保守回退 MA4_proxy。
7. 聚类簇只用于结果分层和解释，不覆盖 SKU 层面的上述判定，也不强制一簇一个模型。

## 3. 方案比较口径

- 方案 A：最终留出窗口共同可评价 SKU 全部使用 MA4_proxy。
- 方案 B：只应用前 5 个窗口冻结的 SKU 路由；第 6 个窗口不得新增或修改路由。
- 两方案必须在完全相同的 SKU 集合上比较，同时报告因首次出现、训练中断或测试缺失而未进入共同集合的数量。
- 除总体结果外，按管理路径、完整期间需求画像和销量贡献拆分，核查提升是否仅由少量高销量 SKU 驱动。

## 4. 可审计性说明

上述数值线在正式 500 次聚类稳定性结果和全部预测结果之前冻结。由于此前已查看 5 次聚类预检，K=3 判定线不是完全结果盲；该局限须在最终报告中保留。预测路由判定线在任何预测结果之前冻结。
