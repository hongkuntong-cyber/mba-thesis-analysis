# 研究协议修订 1.1：跨年拆分周与后续候选选择

修订日期：2026-08-28  
修订时点：已完成工作簿结构审计，尚未计算 V2、特征、聚类或预测指标。  
修订原因：原始工作簿将同一个 ISO 周拆为 `2025-12-29~2025-12-31` 和 `2026-01-01~2026-01-04` 两个跨工作表片段；协议 1.0 未明确该情况。

本修订优先于协议 1.0 的相应条款，其余条款保持不变。

## 1. 周粒度合并

1. 每个日期区间按其覆盖日期映射到星期一开始的 ISO 周。
2. 同一 SKU、同一 ISO 周的多个片段相加，并累计不重复覆盖天数。
3. 只有覆盖 7 个自然日的 SKU—周才进入正式分析。
4. 覆盖不足 7 天的边界周列入审计清单，不将缺失天数静默补 0。
5. 合并后必须重新验证 SKU—周唯一性和周序列连续性。

## 2. 后续回测所需的保守操作候选

完整特征×K结果仍以 Pareto 前沿呈现，不用加权总分。为了在学术结论可能未决时仍能开展无泄漏预测回测，预先规定一个“操作候选”规则：

1. 预设基准为 `ADI + CV² + nonzero_mean + acf1`、Ward K=2。
2. 只有当另一个候选在 Silhouette 和稳定性 ARI 上均不低于该基准，且至少一个指标严格更高时，才可替换基准进入后续回测。
3. 若有多个候选满足条件，先选特征更少者；特征数相同时依次选择稳定性 ARI 更高、Silhouette 更高者。
4. 该规则只为确定回测中的冻结操作方案，不将其自动等同于最终学术结论。
5. K=3 是否成为论文主结果仍须按协议 1.0 的完整结构、画像和稳健性证据判断。
