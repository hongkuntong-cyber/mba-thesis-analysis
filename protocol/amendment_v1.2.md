# 研究协议修订 1.2：中位数特征的结构性冗余处理

修订日期：2026-08-30  
修订时点：已完成完整期间 V2 复现与一次 5 次重复的非正式聚类预检；尚未运行 500 次正式稳定性检验，尚未查看任何预测或最终留出结果。  
修订原因：预检发现 `median_sales` 在当前非负、零值占比较高的周需求数据中主要充当“至少一半观察周是否为正销量”的阈值变量，与理论锚点 ADI 重复表达间歇性。

本修订优先于协议 1.0 的相应特征资格条款，其余条款和修订 1.1 保持不变。

## 1. 已观察到的预检事实

5 次重复仅用于检查代码路径和异常组合，不属于正式 500 次稳定性证据。预检中：

- `ADI + CV² + median_sales`、K=2 的 Silhouette 为 0.5733，稳定性 ARI 中位数为 1.0000；
- 两簇规模为 28 与 169；
- 197 个主样本中，169 个 SKU 的 `median_sales=0`，28 个 SKU 的 `median_sales>0`；
- `median_sales=0` 的 169 个 SKU 全部具有 `ADI≥2.045`；`median_sales>0` 的 28 个 SKU 中，27 个具有 `ADI<2`，另 1 个具有 `ADI=2`。

因此，该高指标首先反映零值质量点造成的近乎确定性二分，而非一个独立、连续的需求规模维度。

## 2. 理论与结构依据

对于非负序列，全部周中位数是否大于 0 主要由正销量周占比是否超过 50% 决定。又因：

`ADI = N_observed / N_positive`

当正销量周占比跨越 50% 时，ADI 同时跨越约 2 的边界。因此，在 ADI 已固定为理论锚点的正式 Ward 组合中，`median_sales` 的零/正状态近似为 ADI 的离散阈值编码，未通过协议中“冗余、有效信息与可解释性”的资格门槛。

该判断基于定义和本数据的零值质量点，不依据后续正式 K 值或预测优劣。

## 3. 修订后的处理

1. `median_sales` 保留在特征计算、簇画像和完整敏感性网格中。
2. 完整敏感性网格仍使用原协议规定的 500 次、80% 无放回子样本稳定性检验，并原样报告其高指标，不删除失败或不利结果。
3. `median_sales` 不再具有确认性主特征集资格，不参与操作候选选择、预测期前冻结选择或论文主结论的特征竞争。
4. 确认性附加特征调整为 `mean_sales`、`std_sales`、`nonzero_mean`、`acf1`，其中 `mean_sales` 与 `nonzero_mean` 仍不得共存。
5. 正式报告必须并列展示：
   - 不含 `median_sales` 的确认性候选结果；
   - 含 `median_sales` 的敏感性结果及其机械阈值解释。
6. 后续不得以正式 500 次指标或预测结果为理由重新恢复或删除该特征。

## 4. 可审计性说明

本修订发生在看到一次 5 次重复预检之后，因此不能称为完全结果盲。为避免事后选择偏差，预检数值和交叉分布已在本文件永久保留；正式网格仍覆盖原候选空间，只把确认性资格与敏感性展示分开。
