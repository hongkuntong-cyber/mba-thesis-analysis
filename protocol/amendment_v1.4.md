# 研究协议修订 1.4：操作候选的簇级稳定性门槛实现

修订日期：2026-08-30  
修订时点：已完成首个预测起点前的 500 次确认性特征—K 网格，并看到未约束选择结果；尚未运行或查看任何 Rolling-Origin 预测结果。  
修订原因：代码中的操作候选函数只实现了修订 1.1 的“双指标支配 + 简约性”步骤，遗漏协议 1.0 已明确规定的“K=4–6 若形成不稳定簇，不得只凭单项或总体指标选用”。

## 1. 已观察且永久保留的未约束结果

首个预测起点为 2025-09-01，训练期聚类样本 N=130。遗漏簇级门槛的初始函数选出：

- 特征：`ADI + CV²`；
- K=5；
- Silhouette：0.3746；
- 稳定性 ARI 中位数：0.5560；
- 簇规模：35、12、38、21、24；
- 五个匹配簇的 Jaccard 中位数最低仅 0.4390。

该结果保存在 `outputs/forecast/pre_first_origin_selection_unconstrained.json`，不得删除或覆盖。

## 2. 实现修正

修订 1.3 已在该正式网格运行前冻结了以下簇级门槛：匹配簇 Jaccard 中位数不低于 0.75、每簇不少于 10 个 SKU 且不少于样本的 5%。为落实协议 1.0 对 K=4–6 的同类稳定性要求，本修订将这三项既有门槛统一应用于所有 K=2–6 操作候选，然后再执行修订 1.1 的基准支配与简约性排序。

具体顺序为：

1. 保留计算有效的候选；
2. 排除任一匹配簇 Jaccard 中位数低于 0.75 的候选；
3. 排除最小簇少于 10 个 SKU 或少于样本 5% 的候选；
4. 在剩余候选中执行“四维 K=2 基准支配 + 特征更少 + 稳定性更高 + Silhouette 更高”的冻结规则。

完整期间的原操作候选四维 K=2 已满足上述门槛，因此完整期间结果不受影响。

## 3. 偏差风险说明

把修订 1.3 中原用于 K=3 的数值门槛明确推广到全部 K，是在看到首个预测起点前 K=5 未约束结果后完成的，因此存在结果知情风险。其依据是修复原协议与代码实现不一致，而不是预测表现；此时尚未运行任何预测。最终报告必须同时列出未约束 K=5 和修正后操作候选，并将本修订列为方法限制。
