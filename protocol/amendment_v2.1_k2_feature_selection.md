# 研究协议修订 2.1：固定 K=2 后的主特征选择

修订日期：2026-08-31  
适用分支：`analysis/theory-first-feature-gate`  
状态：证据登记表已冻结、任何新版特征—K 计算尚未开始

## 1. 修订原因与非追溯性

研究者已明确将两类需求画像作为当前论文的操作性分类，不再把 K 值选择作为本轮主要研究问题。因此，本修订把 `K=2` 固定为主聚类的操作性设定；`K=3–6` 仅保留为结构敏感性结果，不得影响主特征集。

既有仓库中的 K=2、K=3、特征网格和预测结果已经被查看。该决定属于看过旧结果后的方法范围收缩，不能追溯称为预注册。使用现有工作簿产生的新版结果仍属于回顾性方法开发；真正的确认性检验必须使用此前未查看的新周数据，并保持本修订不变。

## 2. 正式候选组合

候选池已在 `protocol/feature_evidence_registry.csv` 中单独冻结。主特征选择只比较：

1. `ADI + CV2`；
2. `ADI + CV2 + approx_entropy`；
3. `ADI + CV2 + trailing_zero_share`；
4. `ADI + CV2 + approx_entropy + trailing_zero_share`。

不得增加、替换或删除特征后继续沿用本修订版本号。

## 3. K=2 主特征选择规则

`ADI + CV2` 是理论基准。每个组合均使用同一主样本、Yeo–Johnson、标准化、Ward K=2，以及 500 次 80% 无放回子样本稳定性协议。

一个补充组合只有先通过以下结构门槛，才可挑战理论基准：

- 每个簇至少 10 个 SKU；
- 最小簇占主样本至少 5%；
- 每个簇的子样本匹配 Jaccard 中位数至少 0.75；
- Silhouette 与稳定性 ARI 均可计算。

设数值容差 `epsilon=1e-12`。补充组合只有同时满足以下条件，才视为支配理论基准：

1. `Silhouette_challenger >= Silhouette_baseline - epsilon`；
2. `ARI_challenger >= ARI_baseline - epsilon`；
3. 至少一个主要指标严格大于基准 `epsilon`。

如果没有补充组合支配基准，主特征集固定为 `ADI + CV2`。

如果有一个或多个支配者，只在支配者之间依次按以下规则选择：

1. 特征数量更少；
2. 稳定性 ARI 中位数更高；
3. Silhouette 更高；
4. 特征名称字典序。

禁止把 Silhouette、ARI、CH 或预测损失加权为综合分数。预测结果不得参与上述选择。

## 4. K=3–6 的地位

K=3–6 继续使用同一候选组合和稳定性协议计算，用于说明是否存在额外结构，但它们：

- 不参与本轮主特征选择；
- 不改变 K=2 的操作性设定；
- 不用于扩充预测算法池；
- 不得因单项指标更高而改写本修订。

## 5. 后续确认性检验

未来新增 8 个完整周后，以当时可见数据复跑。确认性复跑必须沿用：

- 本版 4 项候选池；
